# Security

This repository contains only public standards, synthetic fixtures, and public
verification material. Private keys, private GODD, customer data, production
registries, private Hive membership, and channel configuration do not belong
here.

Report vulnerabilities through GitHub private vulnerability reporting when
available. Do not place secrets or exploit data in a public issue.

The public anchor authenticates this repository's registry. It does not
authorize another estate, Hive, workspace, or deployment.
