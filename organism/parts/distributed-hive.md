The distributed Hive is the end goal: the RAPP/1 network as one Hive of plain folders and files. It is where RAPP/1 LTS ends: a person pulls full RAPP/1 from static data.

- In the draft convention, each repository, a station, keeps its own member space: its card `.rapp/member.md` and what it shares under `.rapp/shared/`, changed by its own commits. The live portfolio's version 7 crawl sees twelve cards, but after that crawl ten more default-branch cards merged; as of 2026-09-26 19:40 UTC, twenty-two repositories publish a card on `main`: the original twelve (RAPP, RAR, rapp-1, rapp-model-hive, rapp-work, hive-hub, rapp-hive-hub, hive-hub-mcp, hive-hub-join, rapp-hive-hub-join, rapp-drift-lint and lisppy) plus rappbook-admin, echo-brainstem, heimdall, cowork-cookbook-rapp, rappter-site, rapp-refresh, rapp-education-shorts, rapp-keyring, rapp-secondbrain and chat. The installer's rides in open pull request `kody-w/rapp-installer#48`, which only the owner merges.
- A Hive root is a Hive's public copy; for the RAPP Hive, `kody-w/rapp-hive-public`. It keeps one pointer per station, `members/<station>.md`; an LTS pointer pins the station's commit and the hash of each file read there. The public copy now publishes 317 pointers: 313 read their station at `HEAD`, and 4 pin an LTS commit on the `rapp1-lts` channel. None of those 4 commits carries a card yet, so today only the newest channel reads a card; the LTS channel reads one once a station's LTS pin includes it.
- Its [portfolio](https://kody-w.github.io/rapp-hive-public/portfolio/PORTFOLIO.html) is the network's notice board: each repository's version, its LTS pin, its channel (`rapp1-lts` or `newest`) and its lifecycle (`active`, `deprecated`, `superseded` or `archived`), with [notices](https://kody-w.github.io/rapp-hive-public/portfolio/NOTICES.html) of deprecations and moves. Each crawl is a new version, recorded by one network pulse. Version 7, crawled 2026-09-26 13:41 UTC, lists 317 repositories, all active, 4 of them on `rapp1-lts`, and its subway map is still the live map until the next crawl.
- It is all found by raw URL, with no server: RAPP's seed, then the operator's beacon, then `estate.json`, then the Hive root, then each station (RAPP Constitution Articles XLVI and XLVII, and proposal 0020).
- LTS, the default, reads each station at its pinned commit and checks every hash. Newest reads each at `HEAD`. The Hive agent's `resolve` reads only the LTS way: each station at its pinned commit, every file checked, into a local copy.
- Hashes prove integrity only. Authenticity needs one signature at the top: the estate owner's signed registry.
- Today the seed's one operator is not accepted, and the beacon and `estate.json` are placeholder status documents, so a walk from the seed stops at the operator's placeholder beacon. The estate kit drafted a real beacon 1.1 and an `estate.json` whose one `hives[]` entry pins the Hive root in the convention's five-member shape, on `kody-w/rapp-estate` branch `experimental/rapp1-distributed-hive`; it pins the public copy at `eafa6de`, a publication that already carries the 317 pointers. RAPP's branch `experimental/rapp1-network-seed-acceptance` pins that beacon in the seed, then accepts the operator once the owner allows it. Nothing there is signed or merged.
