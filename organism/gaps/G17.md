The RAPP Work SDK is built and specified, with six operations and exact plan hashes. The Brainstem does not call it yet, so a person cannot yet reach their workspaces by talking to their Brainstem. Proposal 0017 in `kody-w/rapp-work`, a draft on branch `experimental/gap-g17-brainstem-sdk-agent`, adds a single-file Brainstem agent for it, opt-in: a person copies the one file into `agents/`. It is not accepted. This is a drift finding.
