---
id: G10
gap: An organization cannot bind a folder Hive
home: Canonical `rapp-work/1` §§1, 2, 4
fix: Name the Hive by its id, first commit and founder key fingerprint. A `work.vector` names an accepted head, which must come after the previous one
status: idea
---
An organization binds exactly one Hive, and `work.vector` records only an authenticated `rapp-hive/1` checkpoint. So it has no way to name a folder Hive. One idea, not yet proposed to `rapp-work/1`, names the Hive by its id, first commit and founder key fingerprint, and lets each `work.vector` name an accepted head that comes after the previous one.
