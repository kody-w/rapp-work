The SDK uses "organization" for a pointer-only object, while `rapp-work/1` uses it for the accountable body. Proposal 0011 in `kody-w/rapp-work`, a draft on branch `experimental/gap-g11-workspace-index`, names the SDK's object a "workspace index". It is not accepted.
