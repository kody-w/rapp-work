RAPP Workspace/1's core file manifest lists four READMEs among its repository evidence: the root `README.md`, `protocols/README.md`, and two under `protocols/rapp-workspace/`. `protocols/index.json` records the manifest's hash, so editing a README changes the frozen Workspace/1 identity. The repository's copy of `rapp-work-sdk/1` pins `reference/README.md` the same way. That is why `rapp-workspace` holds back its RAPP/1 badge and "Start here" link. One idea, not yet proposed to RAPP Workspace/1, pins only normative bytes: the specification, schemas, reference code, tests and AI instruction files such as `SKILL.md`. No estate activates Workspace/1 yet, so now is the time.
