RAPP/1 lets an estate declare which Grail kernel each release scope pins, with a signed `grail-kernel` registry entry. No estate does this for the Brainstem yet. Its kernel has two channels, by design: LTS, which RAPP pins in its unsigned `KERNEL_PIN.json` (`kody-w/rapp-installer@brainstem-v0.6.9`), and the newest release (`brainstem-v0.6.16`). This is a drift finding.
