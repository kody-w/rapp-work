Hive Hub is now a folder of markdown cards on its experimental branch. A Hive card carries the Hive's address, its id, its first commit and the founder's key fingerprint. Joining happens in the person's own Brainstem: its Hive agent checks the first commit and the founder key, then writes one signed request file. The hub keeps no state and runs nothing.
