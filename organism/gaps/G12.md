Hive Hub is now a folder of markdown cards on its experimental branch. A Hive card carries the Hive's id, its first commit, the founder's key fingerprint and a channel, and may carry an address. Joining happens in the person's own Brainstem: its Hive agent checks every commit from the first one and shows the founder key to compare, then writes one signed request file. The hub keeps no subscription state and runs nothing.
