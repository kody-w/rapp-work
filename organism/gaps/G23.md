id: G23
gap: The LTS Windows installer cannot pin the LTS kernel
home: "`kody-w/rapp-installer` `install.ps1` at `brainstem-v0.6.9`"
fix: "A version pin in `install.ps1`, in a later release: it takes `--version` since `brainstem-v0.6.14`, so the front door can give Windows users that installer pinned to `v0.6.9`, once that is tried on Windows"
status: open
phase: 2
who: engineering
blocks: brainstem
---
At `brainstem-v0.6.9`, `install.ps1` takes no version pin: it clones `main`, and it updates by resetting to `main`. So a Windows user gets the current kernel, not RAPP/1 LTS. The macOS and Linux `install.sh` accepts `--version`. `install.ps1` gained the same `--version` pin in `brainstem-v0.6.14`, and the newest release keeps it, but nothing in the LTS path uses it yet.
