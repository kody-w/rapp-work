At `brainstem-v0.6.9`, `install.ps1` takes no version pin: it clones `main`, and it updates by resetting to `main`. So a Windows user gets the current kernel, not RAPP/1 LTS. The macOS and Linux `install.sh` accepts `--version`. `install.ps1` gained the same `--version` pin in `brainstem-v0.6.14`, but the advertised `irm | iex` one-liner passes no arguments. Open pull request `kody-w/rapp-installer#49` lets both one-liners pin a release tag through `BRAINSTEM_VERSION`, such as `0.6.9`, and refuses anything else before it changes the machine (a machine without git gets git first, because the check needs it). It is not merged: it is held for the owner, because `kody-w/rapp-installer` ships the Grail kernel.
