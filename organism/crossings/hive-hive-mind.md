Each Private Hive is a sovereign cell of the Hive Mind, so the crossing joins the Hive layer, not one cell. Two organizations work together only by signed consent on both sides and an explicit agreement. Membership is never shared. Folder Hives can be found through Hive Hub cards (G12), but `rapp-federation/1` agreements join Private Hives only.
